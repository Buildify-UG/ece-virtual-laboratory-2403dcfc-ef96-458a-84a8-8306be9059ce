# ElectroLab - Getting Started Guide

## 🎯 Quick Start (5 Minutes)

### Prerequisites
- Node.js 16+ installed
- npm or yarn package manager
- Modern web browser

### Installation

```bash
npm install
npm run dev
# Open http://localhost:5173
```

---

## 📱 First Time User

### 1. Landing Page
- See ElectroLab features
- Sign in or get started

### 2. Sign Up
- Email address
- Password (8+ chars)
- Username (3+ chars)
- Click "Create Account"

### 3. Dashboard
- View your projects
- Browse components
- Access lab

### 4. Browse Components
- Click "Explore Components"
- Search for "battery" or "led"
- View specifications

### 5. Virtual Lab
- Click "Virtual Lab"
- See empty canvas
- Component palette on left

### 6. Create First Circuit
- Add Battery
- Add LED
- Add Resistor
- Connect components
- Click "Run"
- Watch LED light up!

## 🔧 Common Tasks

### Design a Circuit
1. Go to Virtual Lab
2. Add Battery (12V)
3. Add Switch
4. Add Resistor (1kΩ)
5. Add LED
6. Connect: Battery → Switch → Resistor → LED → Battery
7. Click "Run Simulation"
8. Toggle switch ON/OFF
9. Save project

### Submit Component
1. Go to Component Library
2. Search for component
3. Click "Request/Add Component"
4. Fill form with details
5. Upload images (optional)
6. Define pins
7. Add specifications
8. Click "Submit for Review"

### Modify Properties
1. Click component on canvas
2. Edit value in properties panel
3. Run simulation
4. Observe changes

### Save/Load Project
**Saving:**
1. Click "Save" button
2. Enter project name
3. Click "Save"

**Loading:**
1. Go to Dashboard
2. Click project
3. Opens in Virtual Lab

## 🐛 Troubleshooting

**Can't Log In?**
- Check email/password
- Create new account
- Clear browser cache

**Components Not Loading?**
- Check internet
- Refresh page
- Clear cache

**Simulation Won't Start?**
- Verify connections
- Add power source
- Check error messages

**LED Not Lighting?**
- Toggle switch ON
- Check polarity
- Verify connections

**Can't Save?**
- Check login status
- Check internet
- Clear storage
