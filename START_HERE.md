## 🚀 Getting Started

### Step 1: Run the App
```bash
npm install
npm run dev
```

### Step 2: Sign Up
- Go to http://localhost:5173
- Click "Get Started"
- Enter email, password, username
- Click "Create Account"

### Step 3: Explore
- Click "Explore Components"
- Browse the component library
- Click on a component to see details

### Step 4: Design Your First Circuit
- Click "Virtual Lab"
- Search for "battery"
- Drag battery to canvas
- Search for "led"
- Drag LED to canvas
- Search for "resistor"
- Drag resistor to canvas
- Connect: Battery → Resistor → LED → Battery
- Click "Run Simulation"
- Watch the LED light up!

### Step 5: Save
- Click "Save"
- Name your project "My First Circuit"
- Click "Save"

**Congratulations! First virtual circuit created! 🎉**

## 🆘 Troubleshooting

**App won't start?**
```bash
rm -rf node_modules
npm install
npm run dev
```

**Can't log in?**
- Check email/password
- Create new account
- Clear browser cache

**Components not loading?**
- Check internet
- Refresh page
- Clear cache

**Simulation not working?**
- Verify connections
- Add battery
- Check errors
